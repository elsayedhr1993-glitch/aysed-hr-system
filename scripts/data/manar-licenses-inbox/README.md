# منار كلينك — صندوق ملفات التراخيص

ضع هنا ملفات PDF أو صور التراخيص (صحة، بلدية، إطفاء، PAM، …) ثم شغّل:

```bash
npx tsx scripts/import-manar-licenses-from-inbox.ts
npx tsx scripts/import-manar-licenses-from-inbox.ts --apply
```

أو بعد التعديل اليدوي على JSON:

```bash
npm run manar:apply-licenses
```
